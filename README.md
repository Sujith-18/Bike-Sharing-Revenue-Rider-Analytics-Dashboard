# Bike-Sharing-Revenue-Rider-Analytics-Dashboard

## 📌 Project Overview

This project focuses on analyzing **3M+ bike-sharing records** using Microsoft Power BI to understand rider behavior, revenue performance, pricing trends, and seasonal profitability.

The dashboard provides an interactive view of key business metrics, helping users explore riding patterns, identify peak usage periods, and compare business performance across different years.

The project involved exploring the dataset using Microsoft Excel, cleaning and transforming data with Power Query, designing a star schema data model, and developing interactive visualizations in Power BI.

## 🎯 Project Objectives

* Analyze overall revenue and profit performance.
* Understand rider behavior and usage patterns.
* Identify peak riding periods by weekday and hour.
* Track monthly rider trends.
* Compare profitability across seasons.
* Analyze average pricing trends and rider-type distribution.
* Build an interactive dashboard for business performance analysis.

##  Project Workflow

### 1. Data Exploration — Microsoft Excel

* Explored the dataset to understand its structure and available fields.
* Identified relevant business metrics and dimensions for analysis.
* Reviewed the data to determine the key questions the dashboard should answer.

### 2. Data Cleaning & Transformation — Power Query

Imported the dataset into Power BI and prepared it for analysis using Power Query.

The process included:

* Handling missing and null values.
* Identifying and removing duplicate records.
* Addressing inappropriate or inconsistent data.
* Transforming data into a suitable format for analysis.

### 3. Data Modeling — Star Schema

Designed a star schema data model to organize the data and establish relationships between tables.

This helped structure the data for analysis and supported the creation of interactive dashboard visuals.

### 4. Dashboard Development — Power BI

Developed an interactive dashboard using KPI cards, charts, and filters to analyze business performance and rider activity.

Added year-based filters for **2021 and 2022**, allowing users to explore and compare results across the two years.
